# XB AI Advisor 95

Tennis va basketbol uchun professional AI signal/advisor bot.

## Modullar
- The Odds API odds engine
- API-Sports result tracking
- Fuzzy match mapping
- Odds movement history
- Value edge, anomaly score, confidence
- AI validator
- Risk engine: stake suggestion, daily loss guard, consecutive loss guard
- Backtest/learning engine
- Synthetic 1-half totals
- Telegram signal/result/daily report
- Telegram commands: /stats /performance /risk /help
- Railway/GitHub ready

Bot avtomatik pul tikmaydi. Bu professional signal va risk maslahatchi.

## Railway
1. GitHub repo yarating va fayllarni yuklang.
2. Railway → Deploy from GitHub.
3. Volume yarating: `/app/storage`.
4. Variables bo‘limiga `.env.example` qiymatlarini kiriting.
5. Deploy.
